# Third-party notices

Runtime model files and machine-generated deployment inventories are not bundled.
The package locks and retained dependency notices describe this code snapshot.

The selected runtime pins are OpenVINO 2026.4.1, USearch 2.26.6, igraph 1.0.0,
tokenizers 0.23.3 and NumPy 2.5.4. Their shipped licence and notice files, together
with those of the installed dependencies, are preserved under `docs/licences/`.
The manifest distinguishes conditional lock packages not installed in this environment.

model artifacts. A declared model-card licence does not establish that a standalone
licence file was shipped. No model artifact is redistributed by this repository.

NPU device, private library or client deployment.
